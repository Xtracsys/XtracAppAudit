# Security reporting

App Audit is an evidence collection and review tool, not a malware scanner or universal vulnerability database. Signing, Gatekeeper, version matching and policies are separate observations. Unknown is never a clean verdict.

For a potential vulnerability, contact **opensource@xtracsys.com** privately. The maintainer may also enable GitHub's Private Vulnerability Reporting feature for structured submissions. Do not include exploit details, private inventories, tokens or personal paths in public issues.

The maintainer designates **opensource@xtracsys.com** for GitHub project inquiries and security reports. No response-time or support guarantee is currently offered. Security fixes target the latest release; older versions may not receive backports.

Trust boundaries include imported snapshots/settings, installed app metadata, vendor/catalog responses and manually entered URLs. Imported observations are unauthenticated. Never grant access or run an app solely because an audit appears clean.
